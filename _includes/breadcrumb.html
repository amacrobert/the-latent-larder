{%- comment -%} A breadcrumb, rendered twice: once for people and once, as BreadcrumbList JSON-LD, for search engines — which show it in place of the raw URL under the result title. Keeping both in one include means they cannot drift apart and start describing different hierarchies. Usage: {% include breadcrumb.html %} {% include breadcrumb.html parent_name="Recipes by tag" parent_url="/recipes/tag/" %} The current page is the last crumb and is not a link — it is where you already are. It still appears in the JSON-LD, because Google expects the trail to terminate at the page describing itself. {%- endcomment -%}
