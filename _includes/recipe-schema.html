{%- comment -%} schema.org/Recipe as JSON-LD — the only reason a recipe site shows up in search with a photo, a time, and a rating slot instead of a blue link. This is deliberately JSON-LD and not microdata sprinkled through the layout. Google reads both, but mixing them means two partial descriptions of the same dish competing to be the canonical one, and the markup ends up steering the HTML. Keeping it in one block means the page can be restyled freely and the structured data still says exactly what it meant to. Every string goes through `jsonify`, which supplies its own quotes and escapes anything inside — an apostrophe in a title would otherwise end the JSON string early and silently invalidate the whole block. {%- endcomment -%} {%- comment -%} Ingredients: rejoin the "quantity | item" columns the page splits apart, since recipeIngredient wants one readable line. § is the separator only because it cannot occur in the source. {%- endcomment -%} {%- capture ingredients_joined -%} {%- for ingredient in page.ingredients -%} {%- assign parts = ingredient | split: "|" -%} {%- if parts.size > 1 -%} {{- parts[0] | strip }} {{ parts[1] | strip -}} {%- else -%} {{- ingredient | strip -}} {%- endif -%} {%- unless forloop.last -%}§{%- endunless -%} {%- endfor -%} {%- endcapture -%} {%- assign ingredient_list = ingredients_joined | split: "§" -%} {%- comment -%} One category, chosen from the tags by how a cook would file the dish. Ordered most specific first so "dessert, baking" files under dessert. {%- endcomment -%} {%- assign category = nil -%} {%- if page.tags contains "dessert" -%}{%- assign category = "Dessert" -%} {%- elsif page.tags contains "breakfast" -%}{%- assign category = "Breakfast" -%} {%- elsif page.tags contains "appetizer" -%}{%- assign category = "Appetizer" -%} {%- elsif page.tags contains "dip" -%}{%- assign category = "Appetizer" -%} {%- elsif page.tags contains "soup" -%}{%- assign category = "Soup" -%} {%- elsif page.tags contains "salad" -%}{%- assign category = "Salad" -%} {%- elsif page.tags contains "side" -%}{%- assign category = "Side Dish" -%} {%- elsif page.tags contains "bread" -%}{%- assign category = "Bread" -%} {%- elsif page.tags contains "main" -%}{%- assign category = "Main Course" -%} {%- endif -%} {%- assign prep_iso = page.prep_time | iso8601_duration -%} {%- assign cook_iso = page.cook_time | iso8601_duration -%} {%- assign total_iso = page.prep_time | iso8601_total: page.cook_time -%} {%- assign page_url = page.url | absolute_url -%}
